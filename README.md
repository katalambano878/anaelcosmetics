# Storefront Template

Neutral, customizable Next.js storefront starter.

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:3005` in your browser.

## Customize

- Update brand defaults in `context/CMSContext.tsx`.
- Update app metadata in `app/layout.tsx` and `components/SEOHead.tsx`.
- Replace assets in `public/`.
- Configure environment variables before production deployment.
